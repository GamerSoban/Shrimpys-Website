# Birthday Website Plan

## Project Overview

A 3-section birthday website designed as a small interactive gift.

**Deadline:** 8 October 2026  
**Time available:** 12 days  
**Hosting:** GitHub Pages (planned)  
**Media:** Videos only — no images  
**Music:** None planned for now

## Design

### Colour Scheme

- `#f9d1d1` — light pink
- `#ffa4b6` — pink
- `#f765a3` — strong pink

The design should use these colours consistently while keeping the overall appearance clean, soft, and birthday-themed.

### Animation

Use a **normal/moderate amount of animation**.

Animations should make the website feel polished and engaging without becoming distracting or excessive.

Possible uses:

- Section entrance/fade animations
- Smooth scrolling
- Button/link hover effects
- Subtle transitions between elements
- Video section reveal animations

## Site Structure

### Section 1 — Generic HBD

The opening section.

Purpose:

- Immediately communicate the birthday theme
- Create a welcoming first impression
- Introduce the site before the user continues

Potential elements:

- Birthday heading/message
- Decorative elements using CSS
- A prompt or control to continue/scroll

### Section 2 — Letter

A dedicated section containing a personal birthday letter.

Content:

- Text will be provided by the client later

Design goals:

- Make the letter easy and pleasant to read
- Give it a distinct visual identity from the opening section
- Use subtle animations when the section becomes visible

### Section 3 — Videos

A section dedicated to the provided videos.

Content:

- Videos will be provided later
- No images are planned

Design goals:

- Present videos cleanly
- Make video controls easy to use
- Ensure the layout works on both desktop and mobile
- Avoid unnecessary visual clutter around the videos

## Navigation

The site should primarily use **scroll-based navigation** rather than the section-switching approach used in the previous personal birthday project.

Planned flow:

`HBD → Letter → Videos`

Possible navigation features:

- Smooth scrolling
- Simple navigation links/buttons where useful
- Scroll-based section animations

## Development Plan

### Phase 1 — Structure

- Set up the project
- Create the three main sections
- Build the basic HTML structure
- Add navigation/scroll flow

### Phase 2 — Styling

- Apply the colour scheme
- Build the layout for each section
- Make the site responsive
- Add typography and spacing
- Style videos and the letter section

### Phase 3 — Animation

- Add smooth scrolling
- Add section entrance animations
- Add subtle hover/transition effects
- Keep animations moderate and purposeful

### Phase 4 — Client Content

- Add the client's birthday text
- Add the provided videos
- Adjust layouts around the real content
- Confirm whether music is still unnecessary

### Phase 5 — Testing

Test on:

- Desktop
- Mobile
- Different screen sizes
- Different browsers where practical

Check:

- Videos load correctly
- Text is readable
- Scrolling works correctly
- Animations do not interfere with usability
- No layout overflow
- No broken links/assets

### Phase 6 — Deployment

- Initialize/prepare Git repository
- Commit the finished project
- Push to GitHub
- Enable GitHub Pages
- Test the deployed version
- Send the final site link to the client
